# 2D Adventure Game
A 2D top-down style fantasy adventure game.
Explore a vast, scrolling map featuring four distinct biomes,
each with unique enemies and challenging boss fights. Collect loot from chests, and use it
to purchase useful items from the trader!

Controls
[WASD] - general movement
[hold shift] - sprint
[left click] - regular attack
[shift + left click] - Heavy attack
[right click] - shield
[r] - use potion
[q] - swap weapons (sword to bow, bow to sword)
[e] - interact with chests
